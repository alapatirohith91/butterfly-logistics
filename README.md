# Butterfly Logistics

A responsive logistics and courier website inspired by modern global shipping UX patterns.

## Live site
https://alapatirohith91.github.io/butterfly-logistics/

## Features
- Responsive logistics landing page
- Shipment tracking demo UI
- Shipping quote calculator
- Express, freight, e-commerce and international services
- Business industry section
- GitHub Pages deployment via GitHub Actions

> Tracking and quote calculations are demo functionality until connected to a real logistics API/backend.
